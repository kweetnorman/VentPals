# VentPals — App Store Review Notes

> **DRAFT — NOT FOR SUBMISSION.** This repository currently contains a front-end development preview, not a production-ready app. The former reviewer credentials and Parent Code have been removed because credentials must never be published in a public repository. Do not submit this document or reuse any credentials from older builds.

## Current build status

- Child experience: static HTML/JavaScript preview using local browser storage.
- Child onboarding: Welcome → choose a VentPal → create a nickname and PowerWord → choose avatar → privacy overview → My Nest.
- Main Guide experience: front-end design preview only, accessible from the grown-up access placeholder.
- Adult accounts, secure invitations, QR tokens, identity verification, notifications, and verified child-adult connections: not active.
- Firebase/backend work is intentionally deferred until the front end has passed its full launch inspection.

## Review access

There are no production or reusable reviewer accounts in this build. Use fictional information only in the local preview. Do not enter real child information, passwords, identity documents, or contact details.

## Main Guide design preview

1. Open grown-up access.
2. Select “Preview Main Guide connections.”
3. Review the child-request queue and invitation lifecycle.
4. Open the invited-adult acceptance preview from a sample invitation.
5. Complete the child confirmation preview from the child's Nest Connections page.

All transitions are local design demonstrations. No secure account, QR token, or real connection is created.

## Mobile and native features

The mobile/Capacitor materials in this repository are separate development work. Haptics, native sharing, local notifications, offline behavior, and deep links have not been re-certified against the current front-end flow. Verify each feature on actual iOS and Android builds before describing it as available to reviewers.

## Product and safety positioning

VentPals is an emotional learning and reflection tool, not therapy, diagnosis, or a crisis service. The child chooses their VentPal and controls who they ask to connect with. Private journal content is not shared by default.
